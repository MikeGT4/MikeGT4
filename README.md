# Digitalroots

## Agent Tree

A side pane for Claude Code that shows your agents live across all open terminals. You can stop or redirect them, see their cost and add a local model. It is free and open source under the MIT license.

[github.com/MikeGT4/agent-tree](https://github.com/MikeGT4/agent-tree)

## Speech2Anywhere

Hold a key, speak, release: local AI turns your speech into polished text at the cursor, in eight languages, on Windows 11 with no cloud and no subscription.

[speech2anywhere.de](https://speech2anywhere.de) · [github.com/MikeGT4/speech2anywhere](https://github.com/MikeGT4/speech2anywhere)

More at [digitalroots.de](https://www.digitalroots.de).
